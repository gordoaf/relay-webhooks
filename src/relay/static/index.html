Delivery behavior

Successful delivery
Your endpoint returns an HTTP 2xx response.
Temporary failure
Network failures, 408, 429, and 5xx responses are retried with backoff.
Permanent failure
Other errors stop delivery. Inspect the attempt and replay after fixing the receiver.
Repeated messages
Delivery is at least once. Use the webhook-id header to avoid applying the same event twice.
